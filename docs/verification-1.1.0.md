# 1.1.0 发布验收

本次在 Apple Silicon Mac、macOS 26.6 实测，所有自建二进制以 macOS 14 为最低版本。没有在 macOS 14 真机上测试，不宣称完成该系统版本的实机验收。

- 后端完整测试：462 项通过。原开发环境及新装的独立 Python 3.13 环境均通过。
- 前端测试：33 项通过；TypeScript 检查与全新目录构建通过。
- 模拟平台覆盖采集、更正、断点下载、对象身份变化、上传、导入、切片、文件流转、清理凭证和恢复。没有向真实平台新增验收任务。
- 独立 profile、空白数据库、端口 8786 冲突、重复启动、停止、移动和改名、中文及空格路径验证通过。启动时只提供系统工具路径，未调用系统 Python、Node 或 Homebrew。
- 两个真实模型在原推理环境和内置环境中对照两张 3840×2160 私有测试画面，标签、分数和定位质量一致，数值容差 1e-6；覆盖磁盘吊命中及未命中。样本不随源码或 Release 发布。
- 原权重、定位文件及四个推理源码均按 SHA-256 校验。wheel 的固定版本、文件清单和 SHA-256 纳入源码。
- macOS 二进制依赖检查与本地临时签名验证通过；不依赖 Homebrew/Anaconda 或原用户目录。没有 Developer ID、公证或关闭系统安全保护的操作。
- 工作树、Git 历史和解压内容执行高置信凭据扫描。不需要的第三方示例密钥文件不打包；公开 URL 语法示例仅按上游文档的确切文件哈希排除该条规则，其他凭据规则始终生效。

另修复“待核对”的损坏视频无法按原区间重采：新入口复用既有请求身份，不重复创建，不把无效文件批准为成功，新版校验前保留旧版及断点。原算法和模型阈值保持不变。

线上更新先暂停后台并备份，完成任务、结果和更正身份核对后恢复；保留原程序全部 123 条完整视频记录和 126 条切片记录。本包仍使用另一个空白 profile，不携带这些生产数据。

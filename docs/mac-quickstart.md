# 采集助手 · Mac 即用包

适用：Apple 芯片 Mac，macOS 14 或更新版本。无需安装 Python、Node、Homebrew。

1. 解压完整文件夹到本机可写位置，再双击 **采集助手.app**。不要直接在压缩包中运行。
2. 首次打开若系统要求确认，请按 macOS 的“隐私与安全性”提示允许这一个应用。程序未使用开发者证书签名，不需要关闭系统安全保护。
3. 网页打开后，先选择工作区位置，再分别登录质检、采集和视觉AI平台。平台功能需要联网及相应账户权限。
4. 选择“查询与批量采集”“视频查看与更正”或“模型识别与切片”使用对应功能。

在“视频查看与更正 → 进程管理”设置同时下载数量（1–8，默认5）。切片栏目单独设置本地识别数量（1–8，初始3）；两种队列独立运行。调低下载数量不打断当前下载，已保存的设置在重启后继续生效。

关闭网页后，已启动的后台任务继续运行。需要停止时双击同文件夹中的 **停止采集助手.command**，等待当前写入安全结束。停止入口只管理此即用包，不停止旧版程序。

默认使用 8786 端口；端口已占用时自动换用空闲端口并打开正确地址。重复打开应用会回到本包已运行的实例。

本包从空白记录开始，不读取旧版任务或登录信息。记录和用户选择保存的登录信息位于：

`~/Library/Application Support/InspectionVideoGatherStandalone/`

视觉AI连接使用独立的系统钥匙串条目。分发包不包含任何账户、密码或会话。请勿把自己运行后产生的数据目录分享给他人。

更新时先停止旧包，用新版替换应用文件夹；保留上述数据目录和自行选择的视频工作区即可继续原有进度。应用文件夹可以移动或改名；自定义视频目录仍须保持可访问。

两个模型、定位文件和内置工具均随包提供。识别规则及阈值与原项目一致。没有平台权限、外置盘未连接或视频本身损坏时，页面会保留进度并提示处理方式。

包内 `文件校验.json` 记录文件校验值；第三方许可和依赖清单在应用的 `Contents/Resources/licenses` 与 `dependencies.json` 中。源码及 FFmpeg 对应源码随同一 GitHub Release 提供。

# 采集助手 · Mac 即用包

适用 **Apple 芯片 Mac，macOS 14或更新版本**。无需安装 Python、Node、Homebrew。Intel Mac、Windows 和 Linux不能直接运行这个 Mac 包。

## 开始使用

1. 完整解压文件夹到本机磁盘（建议“下载”或“应用程序”目录），双击 **采集助手.app**。保留应用内部文件；不要直接在压缩包中运行。
2. 首次打开若 macOS 提示安全确认，在“系统设置 → 隐私与安全性”按提示允许这个应用。不要关闭系统安全保护。本包未使用开发者证书签名。
3. 网页中的“设置”登录质检、采集和视觉AI平台，其他路径自动配置。没有保存任何分发者的账号、密码或会话。
4. 在“日期采集”查询并核对计划，勾选确认采集；开始时间和时长可逐条修改。在“视频确认”查看或多次更正，点击“确认最终区间并处理”后自动下载、识别并导入照片。
5. 在“处理结果”查看进度及照片。结束后按需要手动点击“清理已结束文件”，不会自动扩大到以后才完成的视频。

下载和识别并行数量在“设置”统一管理。断网、断盘时保留进度；真实身份、模型和成果异常会明确显示，不伪装成完成。平台功能需要联网及账户权限，模型推理在本机执行。

## 停止、移动和更新

关闭网页不停止后台任务。双击 **停止采集助手.command**，等待当前写入结束。停止入口仅管理本包实例，不会停止开发版或其他版本。

默认尝试8786端口；占用时自动换用空闲端口并打开正确地址。重复打开会回到已运行实例。若提示已有版本运行，先使用那个版本的停止入口，再启动新版。

更新或移动应用前先停止。整个文件夹可改名、移动；内部模型及工具路径自动适配。移动时一起保留旁边的“数据”文件夹，进度和文件位置会自动适配。

## 数据与备份

即用包从独立空白记录开始，数据保存到：

`解压后的程序文件夹/数据/`

媒体集中在“数据/媒体”，临时文件位于“数据/临时”，数据库、进度和日志位于“数据/系统”。后续更新只替换应用和停止入口，保留“数据”即可。视觉AI续期信息使用本包独立的系统钥匙串条目，用户选择保存的登录信息仅留在本机。分享安装包时不要附带数据文件夹或钥匙串数据。

备份前先停止程序，备份整个“数据”文件夹。不要删除数据目录来更新应用。

## 文件说明与检查

- **采集助手.app**：网页、后端、两个模型、定位文件、Python3.13／3.11及FFmpeg／ffprobe。
- **停止采集助手.command**：安全停止本版本后台。
- **源码与模型.zip**：实际构建源码、测试、构建脚本与同版本模型，供开发者复现；普通使用无需解压它。
- **文件校验.json**：完整文件、可执行权限及相对链接的校验清单。

若无法启动，先确认下载完整、已完整解压，并检查“数据/系统”中的 `logs/service.log`。平台不可达或存储不可用时，按网页提示恢复；不要反复创建新任务。

第三方许可与依赖清单位于应用的 `Contents/Resources/licenses` 和 `dependencies.json`。FFmpeg及相关组件源码、构建说明与校验文件作为同批交付资料提供。最低系统版本按macOS14构建；实机验证的系统版本列于验收报告。

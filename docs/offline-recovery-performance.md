# 离线恢复与页面提速

本轮保持模型、阈值、抽样与区间算法、并行上限不变。原视频上传继续停用。

## 使用变化

- 完整重下立即登记后台操作。平台或原磁盘不可用时，原批准、处理代次和下载断点保留；前提验证通过后才接管。重复请求与重启复用原操作。
- 最终确认与首次启用同一事务保存；明确的全局、单视频及照片暂停始终保留。
- 本地已登记视频优先播放，支持 Range 和历史版本。播放期间持有读取占用；版本不符时拒绝播放，不跳到另一版本。
- 日期、原片绑定与区间草稿跨栏目和刷新保留。后台版本变化时保留输入并要求重新核对。
- 批选仅作用于当前可见筛选范围和当前修订；最终确认资格由后台给出，尚未采集完成的记录不能确认。
- 采集与处理历史按需展开，每页 20 个视频。分页缩减后直接使用后台实际页码。旧平台扫描位于“设置 → 高级维护”。
- “处理此视频”按确切记录 ID 打开。仍在处理、但曾被隐藏的记录临时显示在顶部；不恢复历史列表，不加入批选，不用同名视频替代。
- 清理区分下一次可清理范围和已经登记的固定清单，显示文件数、已删除字节、剩余字节及等待原因。不会自动扩大已登记清单。

## 恢复边界

断盘、暂时不可写及文件占用自动等待，不消耗上传失败次数。已提交的云端照片导入继续对账，磁盘等待不停止上传进程监控。

文件版本、身份或内容冲突仍需核对，不能因环境恢复而自动批准。真实异常与环境阻塞分别显示。网络中断保留登录信息；最近可达、已登录和等待连接不混为一个状态。

启动不等待平台登录超时。保存的连接在后台恢复，用户手动登录或断开优先；旧恢复响应不能覆盖新会话。

## 性能与回归入口

- 质检详情以实绩身份保存成功检查点：一页 100 条中 1 条失败后，恢复仅补查该条，同时核对分页快照。
- 上传指纹和工作区挂载检查在有界工作线程运行。状态页面读快照，不同步访问外置盘；写前仍执行文件和工作区身份校验。
- 摘要不读取完整照片清单和任务快照；日期页仅补充当前页明细。
- 可见运行项约 4 秒刷新，空闲 15 秒、纯离线等待 30 秒；隐藏页面与折叠历史停止轮询。登记成功立即反馈，后续读取失败单独提示。

后端重点回归：`tests/test_offline_final_restarts.py`、`tests/test_media_environment_recovery.py`、`tests/test_offline_local_views.py`、`tests/test_slicing_presentation.py`。

浏览器回归按[界面验收](ui-validation.md)执行，使用隔离数据、当前控件及模拟接口。旧界面的临时验证脚本已移除；底层故障回归保留在 `tests/`。

运行全套：`.venv/bin/python -m pytest -q`；前端测试：`node --experimental-strip-types --test tests/*.test.mjs`；类型检查：`npm run check`；隔离构建：`npx vite build --outDir build/web --emptyOutDir`。

本轮离线验收不向真实平台创建任务、不测试真实上传、不操作断开的外置盘。真实照片导入、归档和接盘恢复须在连接恢复后另行验证。

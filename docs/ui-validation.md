# 界面验收

日常网站与用户数据保持运行。页面验收使用独立样例或真实视频模拟站，
不对日常网站执行采集、清理或重置。截图和报告保存到 `output/playwright/`，
该目录不进入 Git。

## 隔离页面

先构建到独立目录，再启动临时样例：

```bash
npm run check
npx vite build --outDir build/web --emptyOutDir
RECORD_UI_DIST="$PWD/build/web" RECORD_UI_COUNT=5 \
  .venv/bin/python -m tests.record_management_browser_fixture
```

打开 <http://127.0.0.1:8795/>。样例数据库及文件位于系统临时目录，退出进程后清理。
其中的视频是用于展示记录的占位文件；真实播放、采集和模型处理另用
[真实视频交互体验](interactive-rehearsal.md)验证。浏览器也可由 Playwright CLI 操作。

## 当前操作清单

- 在1440、1024、768和390像素宽度检查四个栏目：主标题只有一个，无横向溢出，切栏不残留旧栏目表单或错误。
- 展开视频日期组，卡片列数依次为3、2、2、1。详情在当前卡片内展开，一次只打开一条，没有侧栏。
- 填写更正草稿并等待一次后台刷新；详情、播放器来源和草稿保持。收起后焦点回到按钮，重新展开可恢复草稿。
- 设置页在1440及1024宽度显示下载、切片进程、图片上传三个等宽栏目；768及390宽度纵排。输入和保存按钮可正常使用。
- 日期查询先显示待确认计划，默认不勾选；逐条修改时间，全选仅选中符合准入的记录，确认后才提交。
- 真实模拟站中测试更正、撤回及再次更正；最终确认后，处理结果立即显示下载阶段，关联切片后只保留一张处理卡片。
- 照片暂停时，视频确认与处理结果均显示等待上传；未核验的照片不得显示完成或具备清理资格。
- 隐藏记录保持隐藏，其未结束照片包仍计入后台等待；更正版不继承旧版的当前进度或成果。

## 自动回归

```bash
npm test
npm run check
npx vite build --outDir build/web --emptyOutDir
```

当前版本的日期确认、撤回、同步状态、迟到读取及文件凭证由 `tests/` 中的
Python和前端测试覆盖。真实解码及模型测试需要用户提供视频和模型，
不把浏览器占位文件或协议模拟结果当作真实识别成果。

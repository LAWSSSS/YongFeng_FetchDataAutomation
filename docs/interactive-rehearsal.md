# 真实视频交互体验（不上传）

`scripts/user_rehearsal.py` 使用普通网页、后台调度和模型。质检记录及采集
任务由隔离模拟器提供；视频来自真实原片，只读使用。下载、预览、连续
更正、版本确认、识别、照片导出及 ZIP 打包实际执行。

模拟质检默认只有鲁NH1113一条记录，日期为 **2026-09-13**，质检09:49–10:01。
这些质检时间是测试数据，不作为真实质检凭证。原片画面覆盖09:54:00至
11:08:59。初次仍从质检开始后5分钟采集60分钟。

## 使用

```sh
.venv/bin/python scripts/user_rehearsal.py \
  --root '数据/临时/新交互体验' \
  --source '数据/测试样本/正常/20260913_095400_鲁NH1113.mp4' \
  --port 8790 --records 3
```

打开 http://127.0.0.1:8790/ 。首次自动填写测试日期，不预先提交。
`--records 3` 提供三条独立模拟质检，时间错开2分钟，共用同一真实原片，便于测试批量确认。
可设置1–5条；原测试目录恢复时条数必须一致，不能覆盖已有进度。

1. 点击“查询待采集视频”，核对并勾选后点击“确认采集所选”，进入“视频确认”，展开提交日期与“查看与更正”。
2. 查看视频后可以多次更正。快速体验可先改为10:04、3分钟，再改为10:05、2分钟；最终确认前可撤回当前更正，恢复上一有效版本，再次修改。
3. 查看最终版本，勾选“我已查看并确认这一版视频”，点击“确认最终区间并处理”。
4. 在“处理结果”查看真实识别进度和照片包；也可以查看历史版本、暂停、继续或管理记录。

上传和照片导入永久停用，相关恢复按钮会明确拒绝。确认后本地流水线
继续，生成照片后停在等待上传，不伪造导入凭证或完整完成状态。尚未
导入的照片及原片不会获得清理资格，这是本测试的预期结果。

所有数据库、模拟任务、下载和照片都在指定测试目录；不读取保存的登录
信息，不修改日常网站或真实云端。退出进程后可用同一命令恢复；模拟
平台任务和视频绑定从日志恢复，不自动生成新任务。原片变化则拒绝复用。

模型、阈值和区间算法保持默认，照片数量由真实判断决定，未检出如实显示。
原片为HEVC，模拟采集只重新封装并增加浏览器兼容标记，不重新编码画面。
非关键帧的开始时间可能有不足一个关键帧间隔的误差，仍执行正式媒体校验。

复现测试：

```sh
.venv/bin/python -m pytest -q tests/test_user_rehearsal.py tests/test_real_video_capture.py
```

本入口不随应用自动启动，也不会重新启用原视频上传。体验过程中关闭
网页不停止后台处理；结束测试时对该测试服务发送普通停止信号。

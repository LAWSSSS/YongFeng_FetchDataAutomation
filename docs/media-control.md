# 统一视频控制与照片包

“视频查看与更正”是单视频指令入口。切片栏目保留批量队列、进程控制、历史记录和结果查看。来源无法唯一关联的未完成文件显示为本地视频，可选择现有采集版本并核对原片后关联；历史已完成文件不重复插入采集记录。

## 身份和恢复

- `simple_media_controls` 保存稳定身份、控制代次、来源关联和已知路径。两个数据集引用同一物理版本时共用身份；仅同名不能建立关联。
- 更正/重采请求登记时预留代次。后台接管只取消该视频的识别、导出和未提交照片包，等待文件线程释放；已提交导入继续对账并记录为旧版。
- 旧任务保存时保留停止标记和已提交凭证；调度、导出、上传及提交前均检查当前代次。新版本未由用户确认并下载，不进入识别。
- 原有文件读写租约继续保护播放、转移、删除。后台更新与重启使用原数据库和既有任务ID。

## 接口

- `GET /api/video-processing` 返回集中控制分组，包括 `id`、`videoId`、`generation`、`owner`、等待原因、切片项、照片包和清理记录。
- `POST /api/video-processing/{id}/actions` 接收 `requestId`、`generation`、`itemId`、`expectedRevision` 及动作参数。动作包含开始、重试、可解码恢复、绑定、区间核对、关联采集版本、照片包确认/核对及受控清理。重放复用凭证，过期请求返回409。
- 旧切片单条修改接口返回409及 `processingEntry` 深链接，直接定位统一入口；全局队列操作继续使用既有接口。
- `POST /api/slicing/packages/{id}/view` 创建或续期查看会话；`contents` 分页列出这个包的照片，`images/{name}` 读取照片，`download` 下载已有 ZIP，`view/close` 释放会话。

## 本地画廊

照片只从已登记路径或对应 ZIP 读取，并核对版本、清单和条目路径。单张上限32 MiB，缩略图最多480×300，内存缓存最多64张。查看会话每30秒续期、120秒超时，清理等待读取租约释放。不读取平台照片、不补采、不重新导入；本地内容已清理时明确不可用。

## 恢复完成与归档重试

两类可用片段的照片包均有逐图导入核验凭证后，自动将当前采集记录归入“已完成”。保留原片解码异常事实，不伪装为完整视频，不重下或重新切片。旧版本或已停止任务不能更新新版。回调和后台巡检均会补记完成结果，历史 attention 操作无需人工再次确认。

单条 `retry-archive` 由统一入口登记，工作区后台按当前绑定重试，接口立即返回排队状态。照片只有在与绑定且已核验的 ZIP 逐字节一致时，才允许刷新变化的文件元数据；真实内容变化仍报错保留。全局“重新核对文件”同样后台执行并返回完成或明确异常。

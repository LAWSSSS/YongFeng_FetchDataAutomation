# 固定数据目录

源码版使用项目根目录的“数据”；Mac 即用包使用与“采集助手.app”并排的“数据”。程序不会向应用内部写入媒体或进度。

```text
数据/
├── 媒体/        原片、历史版本、照片和ZIP，按处理类别自动流转
├── 临时/        隔离测试等临时资料
├── 系统/        数据库、任务凭证、日志和备份
└── 测试样本/
    ├── 正常/
    └── 异常/
```

内部媒体分类保留采集视频、未切片、车斗未切片、磁盘吊未切片、已切片、两类照片结果，以及处理中和缓存分支。照片全部导入且核验通过后才归档。测试样本不参与自动扫描、清理或发布打包。

网页只显示存储状态、已登记文件占用、剩余空间和“打开数据文件夹”。所有目录、模型及工具由程序定位；旧位置修改接口返回409。

关闭程序后可以将整个文件夹移动或改名。数据库用相对路径日志恢复运行路径，保留视频版本、确认和任务凭证。不可写、空间不足或磁盘断开时等待，不改用其他磁盘。移动到另一文件系统造成身份变化时，仍须核实内容，不能只按同名文件认领。

“清理已结束文件”冻结点击时的清单，仅处理本流程登记、两类都已结束且所有照片已核验的文件。无目标或无可用画面必须有明确的处理结论；环境错误不算处理完成。不要求上传原视频，原视频上传保持停用。核验版本并等待播放、识别、下载及上传释放占用后逐文件清理。云端成果、未知文件、模型和桌面原始目录不删除。

记录删除共用相同的文件清理约束。未结束的记录只隐藏；完成但凭证不足的文件保留并说明原因。已清理的成果不自动补下载或重新识别。

旧队列退役为只读凭证；迟到回调不得重新生成列表或重新执行任务。一次性重置脚本须在服务停止、数据库备份、样本完整校验后显式运行，不由启动或普通网页操作调用。

# 无上传流水线验证

仅在独立目录运行，不修改正在运行的网站、数据库或队列。所有平台客户端使用拒绝请求的本地替身；照片上传被持久暂停。真实执行 FFmpeg、两个模型、图片导出和 ZIP 打包，达到“等待上传”后停止，不能把它当成照片已导入。

```bash
.venv/bin/python -B scripts/check_pipeline_without_upload.py \
  --source '/完整路径/原视频.mp4' \
  --settings '/完整路径/不含登录信息的模型配置.json' \
  --root 'data/test-runs/新的唯一目录' \
  --start 600 --duration 600
```

配置允许字段与 `scripts/run_real_video_e2e.py` 相同，也可使用其 `run.json` 中的 `settings`。默认截取 10 分钟，不重编码；原片只读，前后检查大小、时间和 SHA-256。模型、阈值及区间规则不修改。

验证包含持续登记、共用抽帧、两类真实识别、照片包数量、停止上传、重复启动去重、未导入不归档或删除、重启保留暂停和有效观察。`result.json` 保存断言和准确的照片数量，`progress.json` 保存阶段。模型确实未检出时如实保留 `no_target`。

该入口不会启用真实照片导入。生成的测试媒体只位于指定的新目录，诊断确认后按登记的文件清单清理；不要删除原片或对实际工作区执行递归清理。

中断后可用完全相同的源片、配置和区间，加 `--resume` 继续指定测试目录；入口校验已有运行清单后复用登记及有效观察，只有异常类别使用原有单条重试。

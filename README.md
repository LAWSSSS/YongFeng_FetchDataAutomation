# 采集助手使用指南

采集助手帮你按日期找到质检记录，提交视频采集，核对时间，再把识别出的照片导入数据集。所有页面时间均为北京时间。

## 1. 第一次打开

1. 确认电脑是 Apple 芯片 Mac，系统为 macOS 14 或更新版本。
2. 从 [GitHub Releases](https://github.com/zhaochengxiaohao-design/search_download_upload_auto/releases) 下载名称以 `macos-arm64.zip` 结尾的即用包。仓库为私有，无法访问时请找项目负责人开通权限。
3. 完整解压后，双击 **采集助手.app**。浏览器会自动打开。若 macOS 拦截首次启动，先确认安装包来自上述仓库，再按“系统设置 → 隐私与安全性”的提示操作。
4. 进入 **设置 → 平台连接**。用项目负责人提供的信息连接 **质检网站、采集平台、视觉 AI 平台**。前两个用于查询和采集，视觉 AI 平台用于照片导入。

关闭浏览器后，任务仍在后台继续。再次双击应用即可回到页面。

## 2. 完成第一条采集

1. **查记录。** 打开 **日期采集**，选择日期区间，点击“查询待采集视频”。
2. **提交采集。** 核对要处理的记录和采集起止时间，必要时先调整区间。勾选记录并确认采集。可在“采集提交记录”查看提交情况。
3. **确认视频。** 打开 **视频确认**，按提交日期展开，点击“查看与更正”中的“查看视频”。核对画面和时间后，勾选确认，再点击“确认最终区间并处理”。
4. **查看成果。** 在 **处理结果** 等待下载、识别和照片导入。看到完成后，可从结果入口查看照片。上传的是照片包，视频原片留在本机。

如果查不到想要的记录，可先检查日期和“设置”里的采集条件。默认只接受质检时长超过 10 分钟，且有真实车牌或有效智能判级照片的记录。默认采集从质检开始后 5 分钟起，时长 60 分钟。

## 3. 视频时间有误怎么办

| 你要做什么 | 在哪里操作 |
| --- | --- |
| 调整采集时间 | **视频确认 → 查看与更正**。修改开始时间和时长，提交后会生成一个新版本。 |
| 撤回刚提交的更正 | 最终确认前，在“重试与版本操作”点“撤回本次更正”。程序会停止仍在运行的本版采集，清理后恢复上一版。如果详情显示“重试撤回”，先查看提示再操作。 |
| 按相同时间重新采集 | 在“重试与版本操作”点“按当前区间重新采集”。新任务会成为独立版本，原版保留。 |
| 查询提示“已有采集” | 打开提示里的记录或核对入口，优先查看已有任务。若找不到对应任务，在视频详情查看核对原因。 |

“平台排队中”和“等待平台结果”表示采集尚未就绪，可以稍后回来。“待确认”时可以预览。“等待恢复”时先检查平台连接或工作区磁盘。“待核对”时展开详情，按提示处理这条记录。

## 4. 清理本机空间

在 **设置 → 本地数据 → 已完成文件** 点击“一键清理已完成文件”，也可以在 **处理结果** 使用“清理已结束文件”。确认前看一下项目数量和预计释放的空间。

- 清理只处理这次确认范围内的本地下载视频、照片包和相关文件。云端成果和任务历史保留。
- 如果确认时提示清理范围已变化，等页面更新数量和空间后再确认。之后完成的项目可以留到下一次清理。
- 正在播放或处理的文件会等到释放后再清理。磁盘不可用时，重新连接原磁盘。如果某项保留待核对，先看清理结果里的原因。经核实只是归档位置变化的文件，会重新出现在可清理范围内，由你再次确认。

如果只想移除一条日志，请在 **采集提交记录 → 管理记录** 删除该日志。**视频确认**里的“删除记录”会移除显示中的记录，进行中的任务继续处理，符合条件的已结束记录可同时清理对应的本地文件。

## 5. 停止、备份与更新

从应用所在目录停止后台程序。旧版即用包也可使用随包附带的停止入口。

```sh
./采集助手.app/Contents/MacOS/Launcher stop
```

更新或移动应用前，先停止程序并备份旁边的 **数据** 文件夹。这个文件夹存着任务进度和本机成果。移动应用时一起移动它，更新后继续使用原来的数据文件夹。

```sh
sh scripts/setup-slicing-env.sh
.venv/bin/python scripts/fetch_models.py --destination assets/models
sh scripts/build_ffmpeg.sh
```

如果拿到的是含权重的“源码与模型”包，可以跳过下载模型这一步。要停止源码版，在项目目录运行 `./启动简易版.command stop`。

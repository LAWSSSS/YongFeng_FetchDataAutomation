# 简易版质检视频采集

Python 后端与本地网页，用于质检查询、批量采集、人工更正、下载，以及车斗／磁盘吊模型识别与切片。当前页面只保留“查询与批量采集”“视频查看与更正”“模型识别与切片”三个栏目，文件由统一工作区管理。

## 启动

Apple 芯片 Mac（macOS 14+）可从私有仓库的 [Releases](https://github.com/zhaochengxiaohao-design/search_download_upload_auto/releases) 获取已发布的完整包，解压后双击 **采集助手.app**。包内含两个模型、定位文件、Python 和视频工具，无需安装开发环境；使用说明见 [Mac 即用包](docs/mac-quickstart.md)。已发布附件对应各自版本，当前源码的功能以下文为准。

从源码运行需要 Python 3.13、Node.js 22.13+、FFmpeg 和 ffprobe：

```bash
python3.13 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock.txt
npm ci
npm run build
npm start
```

也可双击仓库中的 `启动简易版.command`。默认地址为 <http://127.0.0.1:8786/>，仅监听本机。更换端口使用 `PORT=8787 npm start`。网页开发代理同样读取 `PORT`。

Mac 源码版由独立后台服务运行，关闭启动终端后继续处理，异常退出后自动恢复。双击 `停止简易版.command` 可停止服务；自定义端口使用 `PORT=8787 .venv/bin/python scripts/local_service.py stop`。后台日志在 `data/local-service.log`，服务不设置开机启动。

模型推理使用独立的 Python 3.11 环境：

```bash
sh scripts/setup-slicing-env.sh
.venv/bin/python scripts/fetch_models.py --tag v1.1.0
```

模型资源按 `assets/models/manifest.json` 的 SHA-256 校验，仅权重、定位文件及推理源码参与处理。也可在切片设置中指定已部署的模型和工具。完整包的复现步骤见 [构建与发布](docs/releasing.md)，依赖及许可见 [第三方许可](docs/third-party.md)。

## 查询与批量采集

登录质检网站和采集平台，按日期、每天的时间段和车牌查询。结果分为“已批准”和“未批准”，可选择或全选已批准实绩后直接提交。

- 初采固定为 **质检开始时间 +5 分钟，采集60分钟**；未识别车牌统一按 `VIRTUAL_001` 等命名。
- 准入条件可设置真实车牌、质检时长和智能判级照片最少张数。车牌及照片可选择任一或同时满足，“无”表示不要求该项；时长始终必须严格超过填写的分钟数。
- 默认准入为真实车牌或至少一张有效照片，且质检时长严格超过10分钟。
- “仅采集所选”等待人工确认下载；“采集并下载所选”明确批准下载这些初采版本，平台完成后自动保存。
- 每批最多20条；提交前核对平台任务。提交响应不明先对账，不盲目重发。

准入设置持久保存，应用到当前查询时重新判定已读取的实绩。旧批次、已提交任务和人工更正保留各自的规则和进度。

## 视频查看与更正

按提交日期展开记录，显示原始质检时间、各版本实际采集时间、平台结果和本地保存状态。支持名称、日期、状态及更正历史筛选。日期、批次和单条记录均可删除网页记录并撤销，文件和后台进度保留；不可恢复的文件与平台清理需另选范围。

视频可在线播放。更正经过“填写草稿 → 核对 → 确认重新采集”，支持连续多次更正、撤回尚未替换的更正，以及修改日期和时长（1–120分钟，精确到秒）。请求带修订号及请求ID，过期修改被拒绝。

下载前由用户确认版本。新版校验成功后才替换旧版并按确切绑定清理。末段缺失、解码异常及断点范围错误提供重新下载和重新采集入口，失败时保留旧片与更正。仍有可用云端结果或已验证本地文件的历史版本可独立下载至浏览器目录，不改变当前更正。

“下载进程管理”设置后台同时下载数量 **1–8条，默认5条**，显示运行与排队数量。设置重启后保留；调高立即补充队列，调低等待正在运行的视频结束。下载、校验与保存共同计入运行数量，断网或断盘保留可确认的断点。历史版本的浏览器下载使用独立入口。

详细的记录、恢复与接口说明见 [记录管理](docs/record-management.md)。

单视频的恢复、绑定、重试、区间调整及本地媒体清理统一在本栏目操作。确认更正优先停止旧版本地处理；已提交的平台任务继续按旧版凭证对账，不能覆盖新版。新采集版本经用户确认并保存后才允许切片。详见 [统一视频控制与照片包](docs/media-control.md)。

可解码部分切片、图片上传及导入核验完成后，自动归入“已保存”，保留原片不完整说明。批量操作通过“选择范围 → 全选”执行，范围包括当前筛选结果、可下载当前版及已完成可用部分；记录有新修订时取消过期选择，不覆盖新更正。日期和更正筛选、保存位置及详细参数默认折叠。

## 模型识别与切片

在此栏目连接视觉AI平台，点击 **全部切片**。程序扫描车斗视频集27912及磁盘吊视频集27944，读取21/22类切片日志去重，匹配本地文件、识别区间、提交并核验图片，继续图片包上传和导入。重复点击补充新项目；已完成、处理中和提交不明的操作复用或先对账。

- 默认两个模型共用30秒抽样，同文件同位置只解码一次；磁盘吊需要时细化到10秒并复用有效观察。
- 保持部署模型的预处理、定位检查和阈值。当前默认车斗180张、磁盘吊150张，具体按用户保存的设置执行。
- 本地识别数量可设1–8，初始3。下载、本地识别和图片上传／导入独立运行，平台等待不占本地识别名额。
- 同一物理文件显示一张卡片，展示两个类别的区间、图片数、结果入口和异常。“前往处理”定位到“视频查看与更正”中的对应卡片。
- 缺片、截断、身份不明和真实识别异常单列“需处理”；断网或断盘等待恢复，其他视频继续。

抽样画面在内存中处理，最终照片和压缩包由工作区管理。两个模型、定位文件和桌面“视频抽帧”原目录不被改写。

“查看结果图片”打开指定照片包的本地画廊，支持缩略图、大图和已有 ZIP 下载。只有 ZIP 时直接读取包内照片，不展开到磁盘。查看期间暂缓该包清理，关闭或两分钟无续期后释放；本地已清理时显示不可查看，不从云端取回。

## 工作区与数据

网页顶部只需选择一个父目录，再预览并启用“视频工作区”。原片在“采集视频、未切片、车斗未切片、磁盘吊未切片、已切片”分支间剪切流转，两个类别的照片与压缩包分别归档。每个视频独立文件夹，同名冲突不覆盖，移动同步所有绑定路径。

清理必须同时具备同一视频版本在两个视频集的核验凭证、两类处理终态，以及全部已产生图片的导入核验凭证。网络、磁盘、模型和身份异常不会被当作处理完成。已指定保留的历史上传视频继续留在原位。详见 [工作区说明](docs/workspace.md)。

开发版的进度保存在 `data/collection.sqlite3`，不会迁入原程序的批次。下载断点、人工更正、有效观察、任务及导入凭证均持久保存。升级使用原数据库，切换前先安全暂停并备份，再按断点继续。

登录可选择长期保存在本机。质检和采集平台配置位于项目外的用户应用数据目录；视觉AI续期凭证使用系统钥匙串，访问令牌仅在内存中。分发包使用独立的数据及凭据名称，从空白记录开始。代码库不包含账号密码、令牌、数据库、视频或本机缓存。

## 代码与检查

- `app/`：采集、更正、下载、切片、平台适配、持久队列和文件管理。上传授权、导入日志及路径绑定仍被图片上传、结果核验和已有任务恢复使用。
- `src/`：当前三个栏目、工作区及共享控件；已移除停用的上传核对、自动上传和旧分类移动页面。
- `assets/models/`：模型校验清单和原推理源码；二进制通过私有 Release 分发。
- `scripts/`：启动、环境准备、模型获取、隐私检查及Mac包构建。
- `tests/`：独立数据库、模拟平台及浏览器检查夹具，覆盖现用流程与旧记录恢复。

```bash
npm test
npm run check
npx vite build --outDir build/web --emptyOutDir
.venv/bin/python scripts/scan_secrets.py --history
```

测试不向真实平台创建任务。运行中的网站使用 `dist`，开发验证先构建到独立目录。TypeScript检查同时拒绝未使用的局部变量和参数。视频、模型二进制、依赖、构建产物、数据库、日志、缓存及凭据由 `.gitignore` 排除；提交前仍需执行隐私检查。

仓库保留测试源码和模拟平台夹具，测试生成的截图、缓存、报告及临时媒体不提交。`build/` 仅作打包或验证缓存，可在确认没有相关构建进程后删除并重新生成；正在使用的 `dist/`、虚拟环境、`data/` 数据库和备份、正式 Release 文件应分别管理，不作为源码清理对象。模型原件留在部署位置，通过校验清单及私有 Release 获取，不混入 Git 历史。

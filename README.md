# 采集助手使用说明

采集助手在你的 Mac 上打开一个操作网页。你可以按日期查质检记录，提交并核对视频，再让程序把识别出的照片导入工作平台。网页里显示的时间都是北京时间。

## 1. 下载和打开

**需要 Apple 芯片 Mac（M 系列），系统为 macOS 14 或更新版本。** 点击屏幕左上角的苹果图标，选择 **关于本机**，查看「芯片」和系统版本。

1. 登录有下载权限的 GitHub 账号，点击 **[下载 Mac 完整版 ZIP](https://github.com/zhaochengxiaohao-design/search_download_upload_auto/releases/download/v1.3.3/gather-assistant-1.3.3-macos-arm64.zip)**。也可以从 [GitHub 发布页](https://github.com/zhaochengxiaohao-design/search_download_upload_auto/releases/tag/v1.3.3) 的 **Assets** 下载同一文件。完整包已带齐运行环境、视频工具和识别模型。
2. 在访达的 **下载** 文件夹双击 ZIP。打开解压得到的 **采集助手-Mac-arm64** 文件夹，确认里面有 **采集助手**、**停止采集助手** 和 **使用说明.html**。访达可能隐藏应用文件名结尾的 `.app`。
3. 把解压后的文件夹移到你自己的 **文稿** 或其他可写位置。双击里面的 **采集助手**，等浏览器自动打开。看到页面上方的 **日期采集、视频确认、处理结果、设置**，就可以使用了。

**首次打开时，macOS 可能要求确认。** 如果看到「无法验证开发者」或「Apple 无法检查是否包含恶意软件」，先确认文件来自上面的 GitHub 发布页。点掉提示后，打开 **系统设置 → 隐私与安全性**，找到采集助手，点 **仍要打开**，再按系统提示确认。公司管理的 Mac 若没有这个选项，请联系 IT。此版本未经过 Apple 公证。 [Apple 的首次打开说明](https://support.apple.com/zh-cn/102445)

网站地址以 `127.0.0.1` 开头，网页和后台都运行在这台 Mac 上。下次直接双击 **采集助手** 即可返回网站。网页地址的端口可能随启动变化，建议通过应用打开。

## 2. 第一次连接工作平台

先接入能访问工作平台的网络，再在网页顶部点 **设置**，向下找到 **平台连接**。按下表填写各平台的工作账号和密码。每张卡片都要单独提交。

| 卡片 | 做什么 | 什么时候要连接 |
| --- | --- | --- |
| **质检网站** | 读取日期范围内的质检记录 | 查询前 |
| **采集平台** | 提交采集任务，查看和下载视频 | 提交采集前 |
| **视觉AI平台** | 上传识别照片并导入目标数据集 | 处理照片前 |

填写后点卡片上的连接按钮，等对应卡片显示已连接。前两个平台的 **保存登录** 可以留选，这样下次打开时会尝试自动连接。如果某个平台连接失败，先记下卡片里的提示，核对对应平台的网络、账号和权限。

## 3. 跟着做一条视频

### 查询质检记录

1. 在网页顶部点 **日期采集**。
2. 在「开始日期」和「结束日期」选择要查询的范围。只查一天时，两个日期选同一天。
3. 点击 **查询待采集视频**，等下方出现采集计划。这个按钮只查询，确认后才会提交。

### 核对计划并提交采集

1. 看车牌、质检时间和拟采集区间。默认采集从质检开始后 **5 分钟**起，持续 **60 分钟**。
2. 时间不合适时，在对应记录中调整开始时间和时长，保存修改后再勾选。建议第一次只勾选一条。
3. 点击 **确认采集所选**，按提示确认。下方 **采集提交记录** 会显示提交情况。平台准备视频需要时间；显示排队或等待结果时，稍后查看同一条记录即可。

### 播放视频，确认区间

1. 在网页顶部点 **视频确认**，展开提交日期，找到刚才的车牌，点 **查看与更正**。视频就绪后点 **查看视频**，检查起止画面。
2. 如果时间不合适，输入新的开始时间和时长，再提交更正。等新版本可播放后重新检查。可以重复更正，直到区间符合要求。
3. 区间正确时，勾选 **我已查看并确认这一版视频**，再点 **确认最终区间并处理**。从这里开始，程序会自动下载、识别、打包并导入照片。

刚提交的更正有误时，可在最终确认前打开 **重试与版本操作 → 撤回本次更正**。等上一版恢复后，再核对或重新更正。确实要重做同一区间时，点 **按当前区间重新采集**，旧版仍可查看。

### 查看处理结果

点网页顶部的 **处理结果**，跟踪下载、识别、照片上传和导入核验。照片导入核验结束后，页面才会显示完成。关闭浏览器窗口后，采集助手会继续在后台运行。关闭电脑或让电脑休眠前，可先查看正在运行的任务。

程序导入的是照片。本机下载的视频原片保存在应用旁的 **数据** 文件夹里。

## 4. 常见问题

| 看到的情况 | 怎么处理 |
| --- | --- |
| GitHub 下载链接显示 404 | 完整包存放在私有 GitHub 仓库。确认你已登录有仓库访问权限的账号，再从发布页下载。 |
| 解压后看到 `启动简易版.command` | 你下载的是源码。回到本说明顶部，点「下载 Mac 完整版 ZIP」，或从发布页的 **Assets** 选同名文件。 |
| 提示应用已损坏 | 重新从 GitHub 发布页下载并完整解压。若仍提示损坏，保留提示文字以便排查。 |
| 提示程序位置不可写，或提示先移动应用 | 在访达的 **文稿** 新建「采集助手」文件夹，将两个应用和说明一起拖进去，再双击启动。已使用过的版本先停止，并一并移动 **数据**。 |
| 浏览器没有自动打开 | 再双击 **采集助手**。若弹窗显示本机地址，把该地址粘贴到浏览器地址栏。 |
| 查询没有记录，或记录无法勾选 | 检查日期、质检网站连接及记录旁的原因。默认要求质检时长**超过 10 分钟**，并且有真实车牌或有效智能判级照片。 |
| 视频显示排队、等待平台结果 | 采集平台还在准备视频。在 **视频确认** 稍后查看，等它出现播放入口。 |
| 提示已有采集 | 先打开提示指向的已有记录。确需重做时，从记录详情使用 **按当前区间重新采集**。 |
| 处理显示等待恢复或待核对 | 展开记录，查看具体原因。先检查提示涉及的平台连接、权限或本机剩余空间。 |
| 照片一直在排队 | 在 **设置 → 图片上传与导入** 看是否暂停，再检查 **视觉AI平台** 的连接和数据集权限。 |

反馈问题时，提供 **macOS 版本、操作到哪一步、屏幕上的提示文字**。如果启动弹窗提示查看日志，在应用所在文件夹依次打开 **数据 → 系统 → logs → service.log**。截图和日志请去掉账号、密码、令牌等信息。

## 5. 停止、更新和清理空间

- **停止程序**。双击同一文件夹里的 **停止采集助手**。已有网页标签可能还开着，可以关闭。下次双击 **采集助手**，后台会继续使用之前的数据。
- **更新程序**。先停止旧版，备份旁边的 **数据** 文件夹。将新版解压到另一个位置，把备份的 **数据** 放到新版应用旁，再打开新版。**采集助手** 和 **停止采集助手** 始终放在同一文件夹中。
- **释放空间**。先核对照片导入成果，再在 **处理结果** 点击 **清理已结束文件**。查看数量和大小，确认后清理本机文件。平台成果和任务历史会保留。

## 已经下载了源码？

日常使用直接下载上面的 Mac 完整版。需要运行源码时，在解压目录使用终端，先安装 Python 3.13 和 Node.js 22.13 或更新版本，再运行 `zsh ./启动简易版.command`。要使用照片识别，还需要 Python 3.11、FFmpeg 和 ffprobe，以及 [从 GitHub 下载的 `models-v1.zip`](https://github.com/zhaochengxiaohao-design/search_download_upload_auto/releases/download/v1.3.3/models-v1.zip)。在源码目录运行 `zsh ./启动简易版.command setup-models ./models-v1.zip`，安装后重新启动。源码版可运行 `zsh ./启动简易版.command stop` 停止。
